# ONNI_MONNI — инструкция по запуску (для новичка)

Это твой сайт-портфолио, но теперь он "живой": работает на Python (Flask) и
хранит всё (работы, лайки, комментарии, пользователей) в базе данных SQLite —
это обычный файл `onni.db`, который создастся автоматически при первом запуске.

Ничего из старого сайта не потеряно: все 14 работ, тексты, соцсети, QR-код,
переключатель темы и анимации — на месте, плюс добавлены лайки, комментарии,
счётчик просмотров, регистрация/вход и админ-панель.

---

## Что нужно установить один раз

Тебе нужен **Python 3.10 или новее**.

### Windows
1. Зайди на https://www.python.org/downloads/
2. Скачай и запусти установщик Python.
3. **ВАЖНО:** на первом экране установки поставь галочку **"Add Python to PATH"**, потом жми "Install Now".
4. После установки открой **Пуск → Терминал** (или "Командная строка" / PowerShell).

### macOS
1. Открой **Terminal** (Программы → Утилиты → Терминал).
2. Проверь, есть ли Python:
   ```
   python3 --version
   ```
   Если версия не показалась — установи Python с https://www.python.org/downloads/macos/
   (или через Homebrew: `brew install python3`, если Homebrew уже стоит).

## Шаг 1. Распакуй проект

Распакуй присланный архив `onni_monni_site.zip` в удобную папку, например
на Рабочий стол. Дальше все команды выполняются **внутри этой папки**.

## Шаг 2. Открой терминал в папке проекта

**Windows:** открой папку `onni_monni_site` в проводнике, в адресной строке
проводника напиши `cmd` и нажми Enter — откроется терминал прямо в этой папке.

**macOS:** в Terminal введи `cd ` (с пробелом), перетащи мышкой папку
`onni_monni_site` в окно терминала — путь подставится сам, нажми Enter.

## Шаг 3. Создай виртуальное окружение (изолированное место для библиотек)

**Windows (cmd/PowerShell):**
```
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```
python3 -m venv venv
source venv/bin/activate
```

После этой команды в начале строки терминала должно появиться `(venv)` —
значит окружение активно.

## Шаг 4. Установи зависимости

```
pip install -r requirements.txt
```

Подожди, пока скачаются и установятся Flask и остальные библиотеки.

## Шаг 5. Запусти сайт

```
python app.py
```

(на macOS иногда нужно `python3 app.py`, если просто `python` не находится)

В терминале появится что-то вроде:
```
[i] Создан администратор: логин 'admin', пароль 'admin123' — ОБЯЗАТЕЛЬНО смените после входа!
[i] Загружено 14 демо-работ из старого сайта.
 * Running on http://127.0.0.1:5000
```

## Шаг 6. Открой сайт в браузере

Перейди по адресу: **http://127.0.0.1:5000**

Готово — сайт работает у тебя на компьютере!

Чтобы остановить сервер — вернись в терминал и нажми `Ctrl + C`.
Чтобы запустить снова в следующий раз — просто открой терминал в папке
проекта, активируй окружение (шаг 3) и выполни `python app.py`.

## Как войти как администратор

По умолчанию создаётся аккаунт:
- **Логин:** `admin`
- **Пароль:** `admin123`

Зайди на сайт → "Войти" → введи эти данные → в правом верхнем углу появится
иконка со щитом — это вход в панель `/admin`.

**Обязательно смени пароль после первого входа!** Проще всего — удалить
файл `onni.db` и при следующем запуске задать свой пароль через переменные
окружения (см. ниже), либо создать нового администратора вручную через код.

### Как задать свой пароль администратора сразу (рекомендуется)

Перед первым запуском `python app.py` задай переменные окружения:

**Windows (cmd):**
```
set ADMIN_USERNAME=твой_логин
set ADMIN_PASSWORD=твой_надежный_пароль
python app.py
```

**macOS/Linux:**
```
export ADMIN_USERNAME=твой_логин
export ADMIN_PASSWORD=твой_надежный_пароль
python3 app.py
```

Если файл `onni.db` уже существует — сначала удали его, чтобы админ
пересоздался с новыми данными (все работы при этом снова подгрузятся
из демо-списка; если ты уже добавлял свои работы через сайт — они
удалятся вместе с базой, так что делай это только в самом начале).

## Как добавить/отредактировать/удалить работу

1. Войди как администратор.
2. Нажми на иконку со щитом (или перейди на `/admin`).
3. Кнопка **"+ Добавить работу"** — заполни название, категорию, описание
   и либо загрузи фото с компьютера, либо вставь ссылку на картинку.
4. В таблице работ есть кнопки **"Изменить"** и **"Удалить"** для каждой.
5. Там же снизу — список последних комментариев со кнопкой "Удалить"
   (на случай спама).

## Как это работает для обычных посетителей

- **Гость (не вошёл):** видит все работы, лайки и комментарии, но не может
  сам лайкать/писать — увидит плашку "Зарегистрируйтесь, чтобы лайкать и
  комментировать".
- **Зарегистрированный пользователь:** может ставить/убирать лайк и оставлять
  комментарии под любой работой.
- **Администратор:** всё то же самое + доступ к `/admin`.

## Частые проблемы

**"python: command not found" (Windows)**
Python не добавлен в PATH. Переустанови Python и обязательно отметь
"Add Python to PATH" при установке.

**"Address already in use" / порт 5000 занят**
Уже запущен другой процесс `app.py`. Останови его (`Ctrl+C` в том окне) или
измени порт в самом низу `app.py`: `app.run(debug=True, port=5001)`.

**Сайт открывается, но без картинок в галерее**
Первые 14 работ используют внешние ссылки на изображения (как в исходном
сайте) — для их показа нужен интернет. Собственные загруженные через
админку фото хранятся локально и от интернета не зависят.

**Как перенести сайт на настоящий хостинг**
Локальный запуск (`python app.py`, `debug=True`) подходит только для
тестирования на своём компьютере. Для реального хостинга сайт нужно
разворачивать через production-сервер (например Gunicorn) на сервисе
типа PythonAnywhere, Render или VPS — это отдельная тема, спроси
дополнительно, если понадобится.
