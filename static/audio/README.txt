Положите сюда свой аудиофайл с названием ambient.mp3
(любой спокойный атмосферный трек без авторских прав, например
с сайтов Pixabay Music, Free Music Archive или YouTube Audio Library).

Файл должен называться ТОЧНО: ambient.mp3
Путь: static/audio/ambient.mp3

Без этого файла кнопка плеера в углу сайта будет видна, но при
нажатии появится подсказка "добавьте файл ambient.mp3".
